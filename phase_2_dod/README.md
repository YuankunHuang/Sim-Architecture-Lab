# Phase 2: Data-Oriented Design

**Duration:** 2 weeks  
**Goal:** Make the CPU cache your best friend.

## Drills

| # | Name | Status | Skills |
|:--|:-----|:-------|:-------|
| 2.1 | AOS vs SOA Benchmark | ⬜ | Layout comparison |
| 2.2 | Cache Line Experiment | ⬜ | `perf stat`, cache misses |
| 2.3 | Hot/Cold Splitting | ⬜ | Data separation |
| 2.4 | Data Locality | ⬜ | Access patterns |
| 2.5 | Struct Packing | ⬜ | Padding analysis |

## Capstone

None - concepts applied in future capstones.

## Completion Criteria

- [ ] Can measure cache miss rates with `perf`
- [ ] Understand when to use SOA vs AOS
- [ ] Can identify and fix cache-unfriendly code
- [ ] Know how to pack structs optimally
