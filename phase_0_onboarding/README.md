# Phase 0: C++ Onboarding

**Duration:** 2 weeks  
**Goal:** Transition from C# thinking to C++ thinking.

## Drills

| # | Name | Status | Skills |
|:--|:-----|:-------|:-------|
| 0.1 | Hello CMake | ⬜ | CMake, FetchContent |
| 0.2 | RAII & Smart Pointers | ⬜ | `unique_ptr`, `shared_ptr` |
| 0.3 | Move Semantics | ⬜ | Rvalue refs, `std::move` |
| 0.4 | Templates 101 | ⬜ | Function/class templates |
| 0.5 | STL Deep Dive | ⬜ | `vector`, `unordered_map` |

## Completion Criteria

- [ ] Can create multi-target CMake project from scratch
- [ ] Understand RAII and never use raw `new`/`delete`
- [ ] Can explain when move is better than copy
- [ ] Can write basic function and class templates
- [ ] Comfortable with STL containers and algorithms

## Resources

- *Effective Modern C++* by Scott Meyers (Chapters 1-4)
- [CMake Tutorial](https://cmake.org/cmake/help/latest/guide/tutorial/index.html)
