# Phase 3: Concurrency Foundations

**Duration:** 4 weeks  
**Goal:** Master multi-threaded programming (GIOS prep).

## Drills

| # | Name | Status | Skills |
|:--|:-----|:-------|:-------|
| 3.1 | Thread Creation | ⬜ | `std::thread`, `pthread` |
| 3.2 | Mutex Basics | ⬜ | `std::mutex`, critical section |
| 3.3 | Deadlock Lab | ⬜ | Deadlock prevention |
| 3.4 | Condition Variables | ⬜ | Wait/notify pattern |
| 3.5 | Producer-Consumer | ⬜ | Classic sync problem |
| 3.6 | Thread Pool | ⬜ | Task queue, workers |
| 3.7 | Readers-Writer Lock | ⬜ | `shared_mutex` |
| 3.8 | Thread-Safe Containers | ⬜ | Concurrent data structures |
