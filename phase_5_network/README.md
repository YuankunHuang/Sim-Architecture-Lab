# Phase 5: Network Programming

**Duration:** 3 weeks  
**Goal:** Master socket programming (GIOS prep).

## Drills

| # | Name | Status | Skills |
|:--|:-----|:-------|:-------|
| 5.1 | Socket Basics | ⬜ | `socket`, `bind`, `listen` |
| 5.2 | TCP Echo Server | ⬜ | Blocking TCP |
| 5.3 | UDP Basics | ⬜ | `sendto`, `recvfrom` |
| 5.4 | Non-blocking I/O | ⬜ | `O_NONBLOCK` |
| 5.5 | I/O Multiplexing | ⬜ | `select`, `epoll` |
| 5.6 | Multi-threaded Server | ⬜ | Thread-per-connection |

## Capstone

None - concepts applied in Phase 7.

## Completion Criteria

- [ ] Can implement TCP and UDP servers
- [ ] Understand blocking vs non-blocking I/O
- [ ] Can use `epoll` for scalable servers
- [ ] Can combine threads with networking
